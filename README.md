# 3D 生存战场 - Three.js 第一人称射击游戏

> 
> A browser-based 3D wave survival shooter built with Three.js. Single HTML file, no bundler or backend required.
> 基于 Three.js 开发的网页端 3D 波次生存射击游戏，单 HTML 文件直接运行，无需打包、无需后端。

## 📖 Introduction | 项目介绍

This is an immersive **browser 3D first-person wave survival shooter**. Fight against increasingly tough enemy waves on a closed battlefield. Kill enemies to earn points, pick up health and ammo supplies, and survive as long as possible.
Features enemy AI, collision detection, particle effects, weapon recoil, reloading, wave system, item drops and a full HUD.

这是一款浏览器可直接运行的**3D 第一人称波次生存射击游戏**。玩家在封闭战场内对抗一波波不断变强的敌人，击杀敌人获取分数，拾取生命、弹药补给，挑战更高波次。包含敌人 AI、碰撞、粒子特效、武器后坐力、换弹、波次系统、道具掉落、HUD 血条弹药面板等完整游戏逻辑。
